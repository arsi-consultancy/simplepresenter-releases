# Simple Presenter releases

Installers and the update feed for **Simple Presenter**, presentation software
for churches by [Arsi Consultancy](https://arsi.in).

- **Download:** the newest installer is on the
  [latest release](https://github.com/arsi-consultancy/simplepresenter-releases/releases/latest).
- **Updates:** installed copies check this repository when they start and
  offer a newer version when there is one. Nothing installs without a click.

Windows shows a "Windows protected your PC" notice for a downloaded installer,
because it is not code-signed yet. Choose **More info**, then **Run anyway**.

This repository holds releases only; it has no source code.
